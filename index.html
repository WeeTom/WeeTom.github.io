更舒适的阅读

深色模式更适合夜间；浅色模式更适合强光环境。自动切换可减少手动操作。

  • 跟随系统偏好
  • 支持手动覆盖
  • 设置可持久化

设计更统一

通过 CSS 变量统一管理颜色、阴影与边框，组件在两种主题下保持一致的层级与对比度。

实现简单

使用 prefers-color-scheme 处理自动模式，用 data-theme 处理手动覆盖。 

/* 自动模式（默认） */
@media (prefers-color-scheme: dark) { ... }

/* 手动覆盖 */
html[data-theme="dark"] { ... }
